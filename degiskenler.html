3.1 Değişken Nedir?

Değişken, program içinde bir değeri saklamak için kullanılan isimlendirilmiş alandır.

Örnek:

int age = 32;

Burada:

int → veri tipi

age → değişken adı

32 → değişkene atanan değer

Bir değişkenin değeri sonradan değişebilir:

int age = 32;
age = 33;

3.2 Primitive Veri Tipleri

Java’da sık kullanılan primitive tiplerden bazıları:

int age = 32;
double price = 149.99;
boolean active = true;
char grade = 'A';

Temel olarak:

int → tam sayılar

double → ondalıklı sayılar

boolean → true veya false

char → tek karakter

Diğer sayısal primitive tipler:

byte

short

int

long

float

double

Çok büyük tam sayılar için long kullanılabilir:

long population = 8_000_000_000L;

float kullanırken genellikle değerin sonuna f eklenir:

float rate = 3.14f;

3.3 Primitive ve Reference Type Farkı

Primitive tipler basit değerleri temsil eder.

Örnek:

int age = 32;
boolean active = true;

Reference type ise bir nesneye referans tutar.

Örnek:

String name = "Deniz";

Temel ayrım:

int, double, boolean, char → primitive type

String, array ve nesneler → reference type

Örneğin:

int[] numbers;

int primitive olmasına rağmen int[] bir reference type’tır.

3.4 Değişken İsimlendirme ve camelCase

Java’da değişken isimleri genellikle camelCase ile yazılır.

Örnek:

int userAge = 32;
double accountBalance = 1500.50;
String firstName = "Deniz";

camelCase örnekleri:

firstName

accountBalance

totalPrice

Değişken isimleri sayı ile başlayamaz.

Geçersiz:

int 2age = 32;

Teknik olarak geçerli ama anlamsız isimlerden kaçınılmalıdır:

int a = 32;

Daha anlamlı:

int age = 32;

3.5 Type Casting

Type casting, bir veri tipini başka bir veri tipine dönüştürmektir.

Widening Casting

Daha küçük bir tipten daha geniş bir tipe geçiş çoğu zaman otomatik yapılır.

int number = 10;
double result = number;

Narrowing Casting

Daha geniş bir tipten daha dar bir tipe geçerken açık casting gerekir.

double price = 19.99;
int wholePrice = (int) price;

Sonuç:

19

Ondalık kısım atılır.

3.6 Sabitler ve final

Bir değişkene tekrar değer atanmasını istemiyorsak final kullanabiliriz.

final double PI = 3.14159;

Artık:

PI = 3.14;

yapılamaz.

Sabitlerde isimler genellikle büyük harfle yazılır:

final int MAX_USERS = 100;

Temel mantık:

final → yeniden atama yapılamaz.

3.7 String Temelleri

String, metin tutmak için kullanılır.

String name = "Deniz";

String primitive değil, reference type’tır.

String birleştirme:

String firstName = "Deniz";
String lastName = "Demir";
String fullName = firstName + " " + lastName;

Temel String metodları:

String text = "Java";
text.length();
text.toUpperCase();
text.toLowerCase();

3.8 String Karşılaştırma — == ve equals()

== iki referansın aynı nesneyi gösterip göstermediğini kontrol eder.

equals() ise String içeriklerini karşılaştırır.

String a = new String("Java");
String b = new String("Java");

System.out.println(a == b); // false

System.out.println(a.equals(b)); // true

Kısa kural:

== → aynı referans mı?

equals() → içerik aynı mı?

3.9 null Kavramı

null, bir reference type değişkenin herhangi bir nesneyi göstermediğini ifade eder.

String name = null;

Şu kullanım çalışma anında hata oluşturur:

name.length();

Çünkü ortada kullanılabilecek bir String nesnesi yoktur.

Bu durumda:

NullPointerException

oluşur.

Primitive tipler null olamaz.

int age = null; // hata

Reference type olabilir:

String name = null;

3.10 Wrapper Classes

Primitive tiplerin nesne karşılıklarına wrapper class denir.

Örnekler:

int → Integer

double → Double

boolean → Boolean

char → Character

Örnek:

int age = 32;
Integer wrappedAge = 32;

Generic yapılarda primitive tipler kullanılamaz.

Geçersiz:

List<int> numbers;

Geçerli:

List<Integer> numbers;

3.11 Autoboxing ve Unboxing

Primitive tipten wrapper class’a otomatik dönüşüme autoboxing denir.

int number = 10;
Integer wrappedNumber = number;

Wrapper class’tan primitive tipe otomatik dönüşüme unboxing denir.

Integer wrappedNumber = 20;
int number = wrappedNumber;

Kısaca:

int → Integer = autoboxing

Integer → int = unboxing

3.12 Primitive ve Wrapper Arasındaki Farklar

Primitive tipler null olamaz.

int score = null; // hata

Wrapper class’lar null olabilir.

Integer score = null;

Wrapper class’ların yardımcı metodları da vardır.

Örnek:

String text = "123";
int number = Integer.parseInt(text);

Soru — Cevap

Soru: String name = "Deniz"; satırında String, name ve "Deniz" neyi ifade eder?

Cevap:
String veri tipidir, name değişken ismidir, "Deniz" değişkene atanan değerdir.

Soru: 25 ve 18.75 için hangi veri tipleri uygundur?

Cevap:
25 → int
18.75 → double

Soru: Dünya nüfusu gibi büyük bir tam sayı için int mi long mu kullanılır?

Cevap:
long.

Soru: false ve 'Z' hangi tiptedir?

Cevap:
false → boolean
'Z' → char

Soru: String ve int[] primitive midir?

Cevap:
Hayır. İkisi de reference type’tır.

Soru: Java için uygun değişken ismi hangisidir: user_age, userAge, UserAge?

Cevap:
userAge.

Soru: Aşağıdaki kodda x kaç olur?

double number = 8.75;
int x = (int) number;

Cevap:
8.

Soru: Şu kod geçerli midir?

final int age = 32;
age = 33;

Cevap:
Hayır. final değişkene yeniden değer atanamaz.

Soru: Aşağıdaki kodda result ne olur?

String language = "Java";
String result = language.toUpperCase();

Cevap:
"JAVA".

Soru: Aşağıdaki kod ne yazdırır?

String x = new String("Hello");
String y = new String("Hello");
System.out.println(x.equals(y));

Cevap:
true.

Soru: Şu kod geçerli midir?

int age = null;

Cevap:
Hayır. int primitive type olduğu için null olamaz.

Soru: Neden List<int> yazılamaz ama List<Integer> yazılabilir?

Cevap:
Generic yapılar primitive tiplerle çalışmaz. Bu nedenle wrapper class olan Integer kullanılır.

Soru: Aşağıdaki kodda hangi işlem gerçekleşir?

Integer age = 32;
int value = age;

Cevap:
Unboxing.

Soru: Hangisi null olabilir?

int score;
Integer score;

Cevap:
Integer score.
