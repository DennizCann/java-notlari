Metotlar ve OOP

OOP, verileri ve bu verilerle çalışan davranışları nesnelerde bir araya getirir. Bir öğrencinin adı ve puanı veridir; kendini tanıtması veya puanının güncellenmesi davranıştır. Bu bölümde metotları bu ilişki üzerinden öğreneceğiz.

Her kod kutusu bağımsız bir örnektir. Bir seferde bir örneği Main.java dosyasına kopyalayıp çalıştır. Aynı isimli sınıfların farklı örneklerdeki sürümlerini tek projede yan yana ekleme.

6.1 Sınıflar ve Nesneler

Sınıf, nesnenin hangi verileri ve davranışları taşıyacağını tanımlar. Nesne bu tanımdan oluşturulan örnektir. Sınıfın içindeki veri alanlarına field, davranışlarına metot denir.

class Student {
    String name;
    int score;

    void introduce() {
        System.out.println(name + ": " + score);
    }
}

public class Main {
    public static void main(String[] args) {
        Student first = new Student();
        first.name = "Deniz";
        first.score = 80;
        Student second = new Student();
        second.name = "Ece";
        second.score = 95;
        first.introduce();
        second.introduce();
    }
}

Çıktı:

Deniz: 80
Ece: 95

new Student() yeni nesne oluşturur. first bu nesneye referans tutar; nokta ile alanına veya metoduna erişiriz. İki nesnenin alanları birbirinden bağımsızdır. Student other = first; ise kopya nesne üretmez: iki değişken aynı nesneyi gösterir.

Burada sınıf alanlarına doğrudan eriştik. İleride bunları private yaparak değişiklikleri kontrol edeceğiz. Sayısal nesne alanları başlangıçta 0, boolean alanlar false, referans alanları null değerini alır; yerel değişkenler için aynı kural geçerli değildir.

6.2 Metotlar ve Parametreler

Metot, adı üzerinden çağrılan bir iş parçasıdır. Aynı işi tekrar yazmayı azaltır. int add(int a, int b) tanımında ilk int dönüş tipi, add metot adı, a ve b parametrelerdir. add(3, 4) çağrısındaki 3 ve 4 ise argümanlardır.

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    void show(int value) {
        System.out.println("Sonuç: " + value);
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        int result = calculator.add(3, 4);
        calculator.show(result);
        System.out.println(calculator.add(3, 4, 5));
    }
}

Çıktı:

Sonuç: 7
12

return, void ve Overloading

return sonucu çağıran yere verir ve o metot çağrısını bitirir. Bir değeri ekrana yazdırmak ile döndürmek farklıdır. void metot değer döndürmez; gerektiğinde yalnızca return; ile erken sonlanabilir. Değer döndüren bir metodun normal biçimde tamamlanan bütün yollarında uygun değer dönmelidir.

Overloading, aynı isimde fakat parametre sayısı, tipi veya sırası farklı metotlar yazmaktır. Yalnızca dönüş tipini veya parametrelerin adlarını değiştirerek overloading yapılamaz.

Recursion

Bir metodun kendini çağırmasına recursion denir. Mutlaka durma koşulu ve bu koşula yaklaşan bir adım gerekir. Aşağıdaki örnek yalnızca negatif olmayan küçük sayılar içindir:

class Counter {
    int sum(int n) {
        if (n == 0) return 0;
        return n + sum(n - 1);
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println(new Counter().sum(3));
    }
}

Çıktı:

6

Çağrılar 3 + 2 + 1 + 0 sonucunu oluşturur. Sonsuz veya çok derin çağrılar StackOverflowError oluşturabilir; her problemi recursion ile çözmek gerekmez.

6.3 Constructor ve this

Constructor, yeni nesnenin başlangıç durumunu hazırlayan özel yapıdır. Adı sınıf adıyla aynıdır; dönüş tipi yazılmaz, void bile kullanılmaz. Hiç constructor yazılmazsa derleyici parametresiz bir tane sağlar. Bir constructor yazarsan bu otomatik parametresiz constructor artık eklenmez.

class Student {
    String name;
    int score;

    Student(String name) {
        this(name, 0);
    }

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student("Deniz", 85);
        Student beginner = new Student("Ece");
        System.out.println(student.name + ": " + student.score);
        System.out.println(beginner.score);
    }
}

Çıktı:

Deniz: 85
0

this.name nesnenin alanını, sağdaki name parametreyi gösterir. this(...) aynı sınıftaki başka constructor’ı çağırır. Parametreleri farklı constructor’lar da overload edilebilir. Bu notlarda Java 21 düzenini kullanıyoruz: this(...) veya super(...) constructor’ın ilk komutudur.

6.4 Kapsam ve Değer Aktarımı

Sınıf gövdesinde tanımlanan alan nesnenin durumudur. Metot içinde tanımlanan değişken yereldir; parametre de metodun içinde kullanılır. Bir blokta tanımlanan yerel değişken dışarıdan kullanılamaz. Yerel değişkene okumadan önce değer atanmalıdır.

Java her zaman değer aktarımı yapar. Primitive değer kopyalanır. Nesne gönderildiğinde ise nesnenin kendisi değil, referansın değeri kopyalanır. Bu yüzden nesnenin alanını değiştirmek çağıranı etkileyebilir; parametreye yeni nesne atamak çağıranın referansını değiştirmez.

class Box {
    int value;
}

class Editor {
    void changeNumber(int n) {
        n = 99;
    }

    void changeBox(Box box) {
        box.value = 99;
        box = new Box();
        box.value = 5;
    }
}

public class Main {
    public static void main(String[] args) {
        int number = 10;
        Box box = new Box();
        box.value = 10;
        Editor editor = new Editor();
        editor.changeNumber(number);
        editor.changeBox(box);
        System.out.println(number);
        System.out.println(box.value);
    }
}

Çıktı:

10
99

6.5 Erişim, Paketler ve Encapsulation

Encapsulation, nesnenin iç durumuna erişimi kontrol etmektir. Alanları private yapıp gereken işlemleri metotlarla sunabiliriz. Her alana otomatik getter ve setter eklemek zorunda değiliz; yalnızca ihtiyaç duyulan erişimi açarız.

class Student {
    private int score;

    public int getScore() {
        return score;
    }

    public void setScore(int score) {
        if (score >= 0 && score <= 100) {
            this.score = score;
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();
        student.setScore(85);
        student.setScore(120);
        System.out.println(student.getScore());
    }
}

Çıktı:

85

Bu örnekte geçersiz puan reddedilir ve önceki değer korunur. student.score = 120; dışarıdan yazılamaz. Gerçek uygulamada geçersiz girdiyi kullanıcıya bildirme veya hata üretme yaklaşımı da seçilebilir.

Erişim Belirleyiciler

public: sınıfa erişebilen yerlerden kullanılabilir. private: doğrudan sınıf içi kullanımı hedefler. Belirleyici yazılmazsa package-private olur, aynı paketle sınırlıdır. protected: aynı paketten ve başka paketteki alt sınıflardan, kalıtımın erişim kurallarıyla kullanılabilir. Her yerden erişim sağlamaz.

package ve import

Paketler sınıfları gruplar. Dosyanın başındaki package school;, sınıfın paketini belirtir; kaynak klasörü altında school diziniyle eşleştirilir. import java.util.ArrayList; başka paketteki sınıfı kısa adıyla kullanmamızı sağlar. Import, erişim kısıtlamalarını kaldırmaz. java.lang içindeki String ve System gibi sınıflar ayrıca import istemez.

6.6 static ve final

static üyeler sınıfa, normal alan ve metotlar nesneye aittir. Örneğin okul adı bütün öğrenciler için ortak olabilir; öğrencinin adı ise her nesnede farklıdır. Static üyeye Student.school gibi sınıf üzerinden erişmek daha açıktır.

class Student {
    static String school = "Java Kursu";
    static final int MAX_SCORE = 100;
    final String name;

    Student(String name) {
        this.name = name;
    }
}

public class Main {
    public static void main(String[] args) {
        final Student student = new Student("Deniz");
        System.out.println(Student.school);
        System.out.println(student.name);
        System.out.println(Student.MAX_SCORE);
    }
}

Çıktı:

Java Kursu
Deniz
100

Klasik main metodu static olduğu için Main nesnesi oluşturmadan çağrılabilir. Static bir metot içinde this kullanılamaz; nesne alanına erişmek için bir nesne referansı gerekir.

final değişkene yeniden atamayı engeller. Final nesne referansı, nesnenin bütün alanlarını değişmez yapmaz. final metot override edilemez; final sınıftan kalıtım yapılamaz. static final ortak sabitler için sık kullanılır.

6.7 Kalıtım, Composition ve Polymorphism

Inheritance bir “türüdür” ilişkisi kurar: öğrenci bir kişidir. extends ile alt sınıf oluşturulur. Java’da bir sınıf doğrudan yalnızca bir sınıftan türeyebilir. Constructor’lar miras alınmaz; alt nesne oluşturulurken üst sınıf constructor’ı da çalışır.

class Person {
    private String name;

    Person(String name) {
        this.name = name;
    }

    String describe() {
        return name;
    }
}

class Student extends Person {
    Student(String name) {
        super(name);
    }

    @Override
    String describe() {
        return "Öğrenci: " + super.describe();
    }
}

public class Main {
    public static void main(String[] args) {
        Person person = new Student("Deniz");
        System.out.println(person.describe());
    }
}

Çıktı:

Öğrenci: Deniz

super(name) üst constructor’ı, super.describe() üst metodun uygulamasını çağırır. Üst sınıfta uygun parametresiz constructor yoksa alt sınıf uygun üst constructor’ı açıkça çağırmalıdır.

Overriding ve Polymorphism

Overriding, miras alınan bir nesne metodunun davranışını alt sınıfta yeniden tanımlamaktır. @Override derleyicinin bunu kontrol etmesini sağlar. Overloading farklı parametrelerle aynı adı kullanmaktı; overriding aynı metodu alt sınıfta özelleştirir. Erişim daraltılamaz; private metot override edilmez, static metotlar nesne metodu gibi polymorphism göstermez.

Örnekte referansın tipi Person, nesnenin gerçek tipi Student’tır. Çağrılan nesne metodunun Student sürümü çalışır: bu polymorphism’dir. Üst tip referansıyla yalnızca o tipin sunduğu üyelere erişilebilir. Alt tipe dönüşüm gerekiyorsa instanceof ile uygunluğu kontrol etmek gerekir; her Person bir Student değildir.

Composition

Composition bir “sahiptir” ilişkisidir: öğrenci bir adrese sahiptir. Böyle bir durumda Student extends Address yerine Student içinde Address address; alanı tutarız. Kalıtımı yalnızca kod tekrarını azaltmak için değil, doğru tür ilişkisini modellemek için seçmeliyiz.

6.8 Abstract Sınıflar ve Interface

Soyutlama, kullanım için gerekli davranışı tanımlayıp ayrıntıları uygulamaya bırakır. Abstract sınıf ortak alan, constructor ve hazır metotlar barındırabilir; abstract metotlar gövdesizdir. Abstract sınıftan doğrudan nesne oluşturulamaz.

abstract class Course {
    abstract String title();

    void printTitle() {
        System.out.println(title());
    }
}

interface Enrollable {
    void enroll();
}

class JavaCourse extends Course implements Enrollable {
    @Override
    String title() {
        return "Java";
    }

    @Override
    public void enroll() {
        System.out.println("Kayıt tamamlandı");
    }
}

public class Main {
    public static void main(String[] args) {
        JavaCourse course = new JavaCourse();
        course.printTitle();
        Enrollable registration = course;
        registration.enroll();
    }
}

Çıktı:

Java
Kayıt tamamlandı

Interface bir sözleşmedir. implements bu sözleşmeyi uyguladığımızı söyler. Yukarıdaki gövdesiz interface metodu public ve abstract’tır; uygulaması public olmalıdır. Bir sınıf birden fazla interface uygulayabilir.

Interface’ler nesneye ait değişken alan veya constructor taşımaz. Alanları sabittir: public static final. Ortak gövdeli default ve static metotlar da tanımlanabilir. Ortak durum ve temel uygulama için abstract sınıf; farklı sınıflara ortak yetenek kazandırmak için interface düşünülebilir.

6.9 Nesneleri Temsil Etme ve Karşılaştırma

Sınıflar dolaylı veya doğrudan Object’ten türemiştir. toString() okunabilir metin temsilini verir. Nesnelerde == aynı nesne referansını karşılaştırır. equals() özel olarak tanımlanmazsa Object’in referans eşitliği davranışını kullanır.

Mantıksal eşitliği tanımlarken equals() ile hashCode() birlikte düşünülmelidir. Eşit nesnelerin hash değerleri aynı olmalıdır; aynı hash değeri nesnelerin eşit olduğunu kanıtlamaz. Bu ilişki HashSet ve HashMap için önemlidir.

final class Student {
    private final int id;

    Student(int id) {
        this.id = id;
    }

    @Override
    public boolean equals(Object other) {
        if (this == other) return true;
        if (!(other instanceof Student)) return false;
        Student student = (Student) other;
        return id == student.id;
    }

    @Override
    public int hashCode() {
        return Integer.hashCode(id);
    }

    @Override
    public String toString() {
        return "Student(" + id + ")";
    }
}

public class Main {
    public static void main(String[] args) {
        Student first = new Student(7);
        Student second = new Student(7);
        System.out.println(first == second);
        System.out.println(first.equals(second));
        System.out.println(first);
    }
}

Çıktı:

false
true
Student(7)

6.10 Enum ve İç Sınıflara Kısa Bakış

enum sınırlı seçenekleri anlamlı isimlerle ifade eder. Örneğin kayıt durumu ACTIVE veya COMPLETED olabilir. Enum alan, metot ve constructor içerebilir; yeni enum sabiti new ile oluşturulmaz.

enum Status {
    ACTIVE("Devam ediyor"), COMPLETED("Tamamlandı");

    private final String label;

    Status(String label) {
        this.label = label;
    }

    String label() {
        return label;
    }
}

public class Main {
    public static void main(String[] args) {
        Status status = Status.ACTIVE;
        System.out.println(status);
        System.out.println(status.label());
    }
}

Çıktı:

ACTIVE
Devam ediyor

Bir sınıf başka bir sınıfın içinde tanımlanabilir. Static olmayan inner class bir dış nesneye bağlıdır; static nested class dış nesne gerektirmez. Anonymous class ise bir sınıfı genişleten veya interface’i uygulayan, adı olmayan tek kullanımlık sınıf tanımıdır. Functional interface’in tek davranışı için lambda çoğu zaman daha kısa bir seçenektir.

Soru — Cevap

Soru: Student second = first; yeni nesne oluşturur mu?

Cevap: Hayır. İki değişken aynı nesneyi gösterir; bağımsız nesne için new gerekir.

Soru: Bir metodun sonucu yazdırması, değer döndürmesiyle aynı mı?

Cevap: Hayır. println konsola yazar; return sonucu çağırana verir.

Soru: Yalnızca dönüş tipini değiştirerek overloading yapılır mı?

Cevap: Hayır. Parametre listesi farklı olmalıdır.

Soru: Constructor’a void yazılır mı?

Cevap: Hayır. Constructor’ın dönüş tipi yoktur.

Soru: Bir nesne metoda gönderilirse referansın kendisi değiştirilebilir mi?

Cevap: Parametreye yeni nesne atanması çağıranın referansını değiştirmez. Ancak paylaşılan nesnenin değiştirilebilir alanları etkilenebilir.

Soru: final nesne referansı nesneyi değişmez yapar mı?

Cevap: Hayır. Yalnızca referansa yeniden atamayı engeller.

Soru: Person p = new Student(...); için hangi describe çalışır?

Cevap: Override edilmişse gerçek nesnenin, yani Student’ın nesne metodu çalışır.

Soru: Abstract sınıftan doğrudan nesne oluşturulur mu?

Cevap: Hayır. Somut bir alt sınıf gerekir.

Soru: Bir sınıf iki sınıftan extends ile türeyebilir mi?

Cevap: Hayır; fakat birden fazla interface uygulayabilir.

Soru: equals ile eşit iki nesnenin hashCode değerleri nasıl olmalıdır?

Cevap: Aynı olmalıdır. Tersi zorunlu değildir.
