4.1 Operatörler

Aritmetik Operatörler

Java’da temel matematiksel işlemler için şu operatörler kullanılır:

+   // toplama
-   // çıkarma
*   // çarpma
/   // bölme
%   // kalan (mod)

Örnek:

int a = 10;
int b = 3;

System.out.println(a + b); // 13

System.out.println(a - b); // 7

System.out.println(a * b); // 30

System.out.println(a / b); // 3

System.out.println(a % b); // 1

int / int işleminde sonuç tam sayı olur.

10 / 3 // 3

Ondalıklı sonuç almak için taraflardan en az biri ondalıklı olmalıdır:

10.0 / 3 // yaklaşık 3.33

Atama Operatörleri

En temel atama operatörü:

=

Örnek:

int x = 10;

Bileşik atama operatörleri:

x += 5; // x = x + 5

x -= 2; // x = x - 2

x *= 3; // x = x * 3

x /= 2; // x = x / 2

x %= 4; // x = x % 4

Örnek:

int x = 10;

x += 5; // 15

x *= 2; // 30

Karşılaştırma Operatörleri

İki değeri karşılaştırmak için kullanılır.

==  // eşit mi
!=  // eşit değil mi
>   // büyük mü
<   // küçük mü
>=  // büyük veya eşit mi
<=  // küçük veya eşit mi

Karşılaştırma sonucu her zaman boolean olur.

int age = 20;

System.out.println(age >= 18); // true

System.out.println(age == 20); // true

System.out.println(age != 20); // false

Mantıksal Operatörler

Birden fazla koşulu birlikte değerlendirmek için kullanılır.

&&  // AND
||  // OR
!   // NOT

AND — &&

İki koşulun da true olması gerekir.

int age = 25;
boolean hasLicense = true;

System.out.println(age >= 18 && hasLicense); // true

OR — ||

Koşullardan birinin true olması yeterlidir.

int age = 16;
boolean hasPermission = true;

System.out.println(age >= 18 || hasPermission); // true

NOT — !

Boolean değeri tersine çevirir.

boolean active = true;

System.out.println(!active); // false

4.2 if, else ve else if

if, bir koşul true ise belirli bir kod bloğunu çalıştırır.

int age = 20;
if (age >= 18) {
    System.out.println("Yetişkin");
}

Koşul false olursa blok çalışmaz.

if - else

Koşul doğruysa bir blok, yanlışsa başka bir blok çalıştırılır.

int age = 15;
if (age >= 18) {
    System.out.println("Yetişkin");
} else {
    System.out.println("18 yaşından küçük");
}

else if

Birden fazla koşulu sırayla kontrol etmek için kullanılır.

int score = 75;
if (score >= 85) {
    System.out.println("Pekiyi");
} else if (score >= 70) {
    System.out.println("İyi");
} else {
    System.out.println("Geliştirilmeli");
}

İlk true olan koşul çalışır. Sonraki koşullar kontrol edilmez.

Ternary Operator

Basit if-else işlemlerini tek satırda yazmak için kullanılabilir.

Yapısı:

koşul ? doğruysa_değer : yanlışsa_değer

Örnek:

int age = 20;
String result = age >= 18 ? "Yetişkin" : "Çocuk";

Koşul true ise ? sonrasındaki, false ise : sonrasındaki değer seçilir.

4.3 switch

Bir değişkenin farklı sabit değerlere göre kontrol edilmesinde kullanılır.

int day = 2;
switch (day) {

case 1:

        System.out.println("Pazartesi");
        break;

case 2:

        System.out.println("Salı");
        break;

default:

        System.out.println("Bilinmeyen gün");
}

break, eşleşen case çalıştıktan sonra switch yapısından çıkılmasını sağlar.

default, hiçbir case eşleşmezse çalışır.

4.4 for ve Enhanced for

Belirli sayıda tekrar yapılacağı zaman sık kullanılır.

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

Çıktı:

0

1

2

3

4

for yapısında üç temel bölüm vardır:

for (başlangıç; koşul; değişim)

Örneğin:

for (int i = 0; i < 5; i++)

int i = 0 → başlangıç

i < 5 → koşul

i++ → her tur sonundaki değişim

Enhanced for — for-each

Array veya collection içindeki elemanları sırayla dolaşmak için kullanılır.

String[] names = {"Ali", "Ayşe", "Deniz"};
for (String name : names) {
    System.out.println(name);
}

Çıktı:

Ali

Ayşe

Deniz

Şu ifade:

String name : names

kabaca şu anlama gelir:

names içindeki her elemanı sırayla name değişkenine al.

İndeks bilgisine ihtiyaç varsa klasik for döngüsü daha uygundur.

4.5 while ve do-while

Koşul true olduğu sürece çalışır.

int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}

Çıktı:

1

2

3

Koşul başlangıçta false ise while bloğu hiç çalışmaz.

do-while Döngüsü

do-while yapısında kod bloğu önce çalışır, sonra koşul kontrol edilir.

int i = 5;
do {
    System.out.println(i);
    i++;
} while (i < 5);

Çıktı:

5

Koşul başlangıçta false olsa bile do bloğu en az bir kez çalışır.

Kısa fark:

while → önce koşul

do-while → önce kod, sonra koşul

4.6 break ve continue

break

Döngüyü tamamen bitirir.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        break;
    }
    System.out.println(i);
}

Çıktı:

1

2

continue

Sadece mevcut turu atlar ve döngüye devam eder.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}

Çıktı:

1

2

4

5
