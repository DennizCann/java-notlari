1.1 Java’yı Tanıyalım

Java Nedir? Kısaca Tarihçesi

Java, 1995’te Sun Microsystems tarafından duyurulan bir programlama dili ve platformudur. Sunucu uygulamaları, kurumsal sistemler ve masaüstü yazılımları geliştirmek için kullanılır. Java hakkında

Temel fikir, aynı programı uyumlu bir Java çalışma ortamı bulunan farklı işletim sistemlerinde çalıştırabilmektir. Aşağıdaki JDK, JRE ve JVM kavramları bu yapıyı açıklar.

Java ve Diğer Diller Nerelerde Kullanılır?

Aynı uygulamada birden fazla dil kullanılabilir. Örneğin bir alışveriş sitesinin tarayıcıdaki ekranları JavaScript, siparişleri işleyen sunucusu Java, veri analizleri Python ile yazılabilir. Aşağıdaki alanlar kesin sınırlar değil, yaygın kullanım örnekleridir.

  • Java: Bankacılık, e-ticaret ve kurumsal sistemlerde sunucu tarafı iş mantığı ve API geliştirmede kullanılır. Spring gibi araçlar bu alanda yaygındır. Masaüstü uygulamaları da yapılabilir; Android dünyasında Java koduyla da karşılaşırız, ancak Android’in çalışma ortamı masaüstündeki JVM ile aynı değildir.
  • Python: Veri analizi, yapay zekâ, bilimsel hesaplama ve tekrarlayan işleri otomatikleştirmede kullanılır. Django ve Flask gibi araçlarla web sunucusu da geliştirilebilir. Kısa sözdizimiyle hızlı denemeler yapmaya elverişlidir. Kullanım alanları
  • JavaScript / TypeScript: Web arayüzlerinin etkileşimli davranışlarını yazarız; Node.js ile sunucu tarafında da kullanılabilir. TypeScript, JavaScript’e geliştirme sırasında tür kontrolü ekler ve JavaScript’e dönüştürülür. Java ile JavaScript farklı dillerdir.
  • C#: .NET ekosisteminde web servisleri, masaüstü ve kurumsal uygulamalar; Unity ile oyun geliştirmede kullanılır. Java’ya benzer sınıf ve tür kavramları bulunur, ancak kütüphaneleri ve çalışma ortamı farklıdır.
  • C: İşletim sistemleri, donanım sürücüleri ve gömülü cihazlarda kullanılır. Bellek ve donanıma yakın kontrol sunar; bu kontrol, geliştiriciden daha fazla dikkat ister.
  • C++: Oyun motorları, grafik uygulamaları ve performans gerektiren masaüstü/sistem yazılımlarında kullanılır. Nesne yönelimli programlamayı düşük seviyeli kontrolle birleştirir.
  • Kotlin: Android uygulamaları ve JVM üzerinde sunucu uygulamaları geliştirmede kullanılır. Java kütüphaneleriyle birlikte çalışabilir; daha kısa yazım ve null güvenliği sunar. Sunucu tarafında Kotlin
  • Swift: Özellikle iPhone, iPad ve Mac uygulamalarında kullanılır. Apple platformlarının arayüz ve sistem araçlarıyla bütünleşir.
  • Go: Ağ servisleri, bulut altyapısı ve komut satırı araçlarında kullanılır. Sade dil yapısı ve eşzamanlı işler için sunduğu araçlar öne çıkar. Kullanım alanları
  • Rust: Sistem araçları, performans odaklı servisler ve düşük seviyeli yazılımlarda kullanılır. Bellek güvenliğini derleme sırasında denetleyen kurallarıyla öne çıkar.
  • PHP: Sunucu tarafında web sayfaları ve web uygulamaları geliştirmede kullanılır. WordPress ve Laravel bu ekosistemin örnekleridir.
  • SQL: İlişkisel veritabanlarında veri sorgulama ve güncelleme dilidir. Genellikle Java gibi bir uygulama dilinin yanında kullanılır; tek başına bir web arayüzü oluşturmaz.

Java öğrenirken değişken, koşul, döngü ve metot gibi ortak kavramları da öğreniriz. Başka bir dile geçtiğimizde bu temel bilgiler işimize yarar; değişen şey sözdizimi, araçlar ve bazı çalışma kurallarıdır.

Yıllara Göre Java Sürümleri

1995, Java’nın duyurulduğu yıl; 1996 ise JDK 1.0’ın yayımlandığı yıldır. Aşağıdaki özet ana sürümleri gruplar; her yama güncellemesini listelemez. Yeni kavramları şimdi ezberlemene gerek yok.

  • 1996–1997 · 1.0 ve 1.1: İlk sürümler; temel dil, kütüphaneler ve veritabanı bağlantısı gibi yeteneklerin gelişimi.
  • 1998 · 1.2: Collections Framework ve Swing ile koleksiyonlar ve masaüstü arayüzleri genişledi.
  • 2000 · 1.3 / 2002 · 1.4: Çalışma ortamı iyileştirmeleri; 1.4’te assert, regex ve yeni I/O araçları.
  • 2004 · Java 5: Generics, enum, enhanced for ve autoboxing gibi bugün sık kullanılan özellikler.
  • 2006 · Java 6: Araçlar, performans ve kütüphanelerde iyileştirmeler.
  • 2011 · Java 7: Try-with-resources, diamond operatörü ve dosya işlemleri için NIO.2.
  • 2014 · Java 8 (LTS): Lambda, Stream API ve yeni tarih/saat API’si.
  • 2017 · Java 9: Modül sistemi ve küçük kod denemeleri için JShell.
  • 2018 · Java 10 ve 11: 10’da yerel değişkenlerde var; 11’de LTS sürümü ve tek kaynak dosyasını doğrudan çalıştırma.
  • 2019–2020 · Java 12–15: Switch ifadeleri ve metin blokları gibi yeniliklerin önizlemelerden kalıcı özelliklere geçişi.
  • 2021 · Java 16 ve 17: 16’da record kalıcı oldu; 17 LTS sürümüdür ve sealed sınıfları kalıcılaştırdı.
  • 2022–2023 · Java 18–20: 18’de varsayılan UTF-8; sonraki sürümlerde yeni dil ve eşzamanlılık özelliklerinin önizlemeleri.
  • 2023 · Java 21 (LTS): Virtual threads ve pattern matching for switch gibi yenilikler. Bu kursta kullandığımız sürüm.
  • 2024–2025 · Java 22–24: Yeni API’ler, performans geliştirmeleri ve sonraki sürümlere hazırlık sağlayan önizlemeler.
  • 2025 · Java 25 (LTS): Yeni uzun süreli destek sürümü; daha sade başlangıç programları ve constructor gövdelerinde esneklik.
  • 2026 · Java 26 ve 27: Altı aylık sürüm düzenindeki yeni ana sürümler; dil, API ve JVM gelişimi sürüyor.

LTS, uzun süreli destek anlamına gelir; süre ve koşullar JDK sağlayıcısına göre değişir. Yeni ana sürümler yaklaşık altı ayda bir çıkar. Kurs için en yeni sürüme geçmek zorunda değilsin: JDK 21’in güncel yamasını kullanıyoruz. 21.0.x aynı ana sürümün güncellemelerini ifade eder. Sürüm tarihleri · LTS bilgileri · Güncel sürümler

1.2 Java’nın Çalışma Mantığı

JDK Nedir?

JDK, Java Development Kit ifadesinin kısaltmasıdır.

Java uygulamaları geliştirmek için gereken araçları içerir. Java kodunu derleyen javac derleyicisi de JDK içerisinde bulunur.

Kısaca:

JDK = Java geliştirmek, derlemek ve çalıştırmak için kullanılan geliştirme paketi.

JRE Nedir?

JRE, Java Runtime Environment ifadesinin kısaltmasıdır. Java ile yazılmış programların çalışması için gereken ortamı sağlar. JVM ve Java'nın çalışması için gerekli kütüphaneleri içerir.

Kısaca:

JRE = Java programlarını çalıştırmak için gereken ortam.

JVM Nedir?

JVM, Java Virtual Machine ifadesinin kısaltmasıdır.

Derlenmiş Java bytecode'unu çalıştırır.

Java kaynak kodunu bytecode'a dönüştüren JVM değildir. Bu işi JDK içerisinde bulunan javac derleyicisi yapar.

Java programının temel çalışma akışı:

Hello.java
    ↓ javac
Hello.class
    ↓ JVM
Program çalışır

.java dosyası kaynak koddur.

javac kaynak kodu .class dosyasına dönüştürür.

.class dosyasının içerisinde Java bytecode'u bulunur.

JVM bu bytecode'u çalıştırır.

Bu yapı Java'nın farklı işletim sistemlerinde çalışabilmesini sağlayan temel nedenlerden biridir.

Bytecode Nedir, Dönüşüm Nasıl Gerçekleşir?

Kaynak kod, bizim okuyup yazdığımız Java metnidir. Bytecode, bu kod derlendiğinde oluşan, JVM’nin anlayacağı daha düşük seviyeli komutlardır. Bytecode, belirli bir işlemcinin doğrudan çalıştırdığı makine koduyla aynı şey değildir.

  1. Yaz: Hello.java içinde sınıflar, metotlar ve komutlar bulunur.
  2. Derle: javac Hello.java sözdizimini ve tür kurallarını denetler. Başarılı olursa bytecode ile sınıf bilgilerini taşıyan Hello.class oluşur. Bir kaynak dosya birden fazla sınıf içeriyorsa birden fazla .class üretilebilir.
  3. Çalıştır: java Hello JVM’yi başlatır; JVM gerekli sınıfları yükler, doğrular ve main metodundan yürütmeyi başlatır.
  4. İşlemcide yürüt: HotSpot JVM, bytecode’u yorumlayabilir; sık çalışan bölümleri JIT derleyicisiyle o makinenin işlemci koduna çevirerek hızlandırabilir.

Aynı .class dosyası, uygun Java sürümü bulunan Windows, Linux veya macOS üzerinde çalışabilir. İşletim sistemine uygun olan parça JVM’dir. Yine de işletim sistemine özel kütüphaneler ve dosya yolları taşınabilirliği etkileyebilir. Yeni Java ile üretilen bytecode, daha eski JVM’de her zaman çalışmaz.

Uzantı değiştirmek derlemek değildir: Hello.txt → Hello.java yalnızca dosya adını değiştirir. Hello.java → Hello.class dönüşümünü ise javac yapar. .class, düzenlemeyi sürdürdüğümüz metin dosyası değildir. HotSpot ve JIT

1.3 Kurulum ve İlk Program

JDK Nereden İndirilir?

SDK, yazılım geliştirme araçları için kullanılan genel addır. Java için ihtiyaç duyduğumuz geliştirme paketi JDK’dır. JDK kurunca bu örnekler için ayrıca JRE kurman gerekmez.

Neden Eclipse Temurin Tercih Ettik?

Eclipse Temurin, Eclipse Adoptium projesinin OpenJDK tabanlı, açık kaynaklı ve ücretsiz JDK dağıtımıdır. Java uyumluluk testlerinden geçmesi, farklı işletim sistemleri için hazır kurulum sunması ve JDK 21 seçimini kolaylaştırması nedeniyle kurs için bunu seçtik. Ayrı bir Java dili değildir; aynı Java kodunu uyumlu başka JDK dağıtımlarıyla da çalıştırabiliriz. Eclipse Adoptium

Eclipse Temurin ile Eclipse IDE aynı şey değildir. Temurin derleme/çalıştırma paketidir; Eclipse IDE kod yazma ortamıdır. Temurin’i IntelliJ IDEA ile kullanabiliriz. “Eclipse SDK” ifadesi yerine burada indirdiğimiz pakete Temurin JDK demek daha doğrudur.

Temurin JDK Kurulumu

  1. Eclipse Temurin indirme sayfasını aç. Bu notlar için JDK 21’in güncel yama sürümünü seçebilirsin. 21 bir LTS, yani uzun süre desteklenen sürümdür.
  2. İşletim sistemini ve işlemci mimarini seç. Standart Intel/AMD Windows bilgisayarlarda Windows / x64 / JDK / .msi uygundur; ARM cihazlarda mimariyi ayrıca kontrol et.
  3. Kurulumda PATH’e ekleme seçeneğini açık tut. JAVA_HOME seçeneğini de etkinleştirebilirsin. PATH komutların bulunmasını sağlar; JAVA_HOME, JDK’nın kurulu olduğu klasörü belirtir.

Kurulumdan sonra yeni bir Komut İstemi (cmd) aç ve kontrol et:

java -version
javac -version

İki komut da sürüm bilgisi göstermeli. javac tanınmıyorsa JDK kurulumunu ve PATH içindeki JDK bin klasörünü kontrol et; ardından terminali yeniden aç. Windows kurulum rehberi · LTS sürümleri

Java.com’dan İndirmek İstersek?

Java.com’un standart indirme sayfası, Java 8 ile hazır masaüstü programlarını çalıştırmaya yöneliktir. Bu paket, ders için gereken JDK 21’in yerine geçmez; yalnızca java komutunun bulunması javac’ın da kurulduğu anlamına gelmez.

  1. Kod geliştirmek için: Java.com’daki geliştirici/JDK bağlantısını izle veya doğrudan Oracle JDK indirme sayfasını aç.
  2. Kursla aynı sürüm için JDK 21 bölümünü, ardından işletim sistemini seç. Intel/AMD Windows bilgisayarda x64 Installer veya x64 MSI Installer ile kurulumu yap.
  3. Yeni terminalde java -version ve javac -version çalıştır. İkisi de seçtiğin sürümü göstermeli. Gerekirse JDK’nın bin klasörünü PATH’e ekle; IDE’de de aynı JDK’yı seç.

Yalnızca hazır bir Java 8 uygulamasını çalıştırmak için: Uygulamanın istediği sürümü doğrula; java.com indirme sayfasında işletim sistemine ve mimarine uygun paketi seçip kurulum sihirbazını tamamla. Bu yol, bu kursta kod derlemek için seçtiğimiz yol değildir.

Temurin ve Oracle JDK aynı Java standardını uygular; dağıtım, destek ve lisans koşulları farklı olabilir. Oracle indirme sayfasında seçtiğin sürüme ait koşullar gösterilir.

Komut Satırında İlk Java Programı

Boş bir klasörde Yeni → Metin Belgesi ile Hello.txt oluştur. Not Defteri’nde aç, aşağıdaki kodu yaz ve kaydet. Ardından aşağıdaki adımlarla uzantısını .java yapacağız:

public class Hello {
    public static void main(String[] args) {
        System.out.println("Merhaba Java!");
    }
}

Önemli Adım: Hello.txt → Hello.java

  1. Kodu kaydettikten sonra Not Defteri’ni kapat.
  2. Dosya Gezgini’nde dosya adı uzantılarını göster. Windows 11’de Görünüm → Göster → Dosya adı uzantıları; Windows 10’da Görünüm sekmesindeki Dosya adı uzantıları seçeneğini kullan.
  3. Hello.txt dosyasına sağ tıkla → Yeniden adlandır. Sondaki .txt bölümünü silip .java yaz: sonuç tam olarak Hello.java olsun.
  4. Uzantıyı değiştirme uyarısını onayla. Hello.java.txt yanlış, Hello.java doğru. Uzantılar gizliyken yalnızca görünen ada “.java” eklemek yeterli değildir.

Dosyanın içeriği hâlâ düz metindir; uzantıyı değiştirmek kodu çalıştırmaz. Bir sonraki adımda javac ile derleyeceğiz. Alternatif olarak Not Defteri’nde Farklı Kaydet → Dosya türü: Tüm dosyalar → Hello.java, kodlama: UTF-8 seçerek baştan doğru adla kaydedebilirsin.

Dosya adındaki Hello ile public class Hello aynı olmalı. Kodun ayrıntılarını ikinci bölümde inceleyeceğiz.

Windows Dosya Gezgini’nde bu klasörü aç; adres çubuğuna cmd yazıp Enter’a bas. Açılan komut satırında sırayla çalıştır:

javac Hello.java
java Hello

javac, Hello.class dosyasını üretir. java Hello programı başlatır; bu komutta .class uzantısı yazılmaz.

Çıktı:

Merhaba Java!

Java 11 ve sonrasında bu tek dosyalık örneği java Hello.java ile de çalıştırabilirsin. Bu yöntem derlemeyi arka planda yapar. Resmî başlangıç rehberi

1.4 IDE ile Çalışma

IDE, kod yazma, çalıştırma ve hata ayıklama araçlarını bir araya getiren geliştirme ortamıdır. Komutları her seferinde elle yazmak yerine Run düğmesiyle çalıştırabilirsin.

  • IntelliJ IDEA: Akıllı kod tamamlama, yeniden adlandırma ve hata ayıklama araçları sunar. Kursta bununla ilerleyebiliriz; temel Java özellikleri ücretsiz, bazı ileri özellikler abonelik kapsamındadır.
  • Eclipse IDE: Eklentilerle genişletilebilen açık kaynaklı bir ortamdır. Java için “Eclipse IDE for Java Developers” paketi başlangıç seçeneğidir. Temurin JDK ile karıştırma.
  • Apache NetBeans: Java projeleri, kod tamamlama ve hata ayıklama için bütünleşik araçlar sunar. Swing masaüstü arayüzlerini görsel olarak tasarlama araçları da bulunur.
  • Visual Studio Code: Temelde bir kod editörüdür. JDK ve Extension Pack for Java kurulduğunda Java proje yönetimi, çalıştırma ve hata ayıklama yetenekleri eklenir.
  • BlueJ: Eğitim odaklı, sade bir Java IDE’sidir. Sınıfları ve nesneler arasındaki ilişkileri görerek OOP öğrenmek için tasarlanmıştır.
  • Android Studio: Android uygulamaları için tasarlanmıştır; cihaz emülatörü ve mobil arayüz araçları içerir. Java/Kotlin destekler, fakat bu kurstaki basit konsol örnekleri için gerekli değildir.

IntelliJ’de New Project → Java yolunu izle, JDK olarak kurduğun sürümü seç. Projenin src klasöründe Hello sınıfını oluştur, yukarıdaki kodu ekle ve main yanındaki çalıştırma düğmesine bas. JDK listede yoksa Add JDK ile kurulum klasörünü gösterebilirsin. IntelliJ başlangıç rehberi

IDE ile JDK farklıdır: IDE çalışma alanındır; projeyi derlemek ve çalıştırmak için seçtiği JDK’yı kullanır.

Soru — Cevap

Soru: Hello.java dosyasını .class dosyasına dönüştüren şey nedir?

Cevap: JDK içerisinde bulunan javac derleyicisidir.

Soru: JVM'in temel görevi nedir?

Cevap: Oluşturulmuş Java bytecode'unu çalıştırmaktır.

Soru: JRE'nin görevi nedir?

Cevap: Java programlarının çalışması için gereken çalışma ortamını sağlamaktır.

Soru: Bir bilgisayarda Java kodu geliştirilmeyecek, sadece hazır Java programları çalıştırılacaksa teorik olarak JDK mı JRE mi gerekir?

Cevap: JRE yeterlidir.

Soru: Hello.txt dosyasını Hello.java yapmak kodu derler mi?

Cevap: Hayır. Yalnızca uzantı değişir; bytecode üretmek için javac kullanılır.

Soru: Temurin kullanırken Eclipse IDE kullanmak zorunda mıyız?

Cevap: Hayır. Temurin JDK, IntelliJ gibi başka geliştirme ortamlarıyla da kullanılabilir.

Soru: Java.com’dan standart Java indirmesi yapmak bu kurs için yeterli mi?

Cevap: Hayır. Kod geliştirmek için JDK gerekir; kursta JDK 21 kullanıyoruz.

Kısa Hatırlatma

JDK → geliştirir ve derler

JRE → çalışma ortamını sağlar

JVM → bytecode'u çalıştırır

En kısa haliyle:

JDK geliştirir, javac derler, JVM çalıştırır.
