İlk Java Programı ve main Metodu

Bu bölümde
public class Mainmain MetoduKodların Çalışma SırasıSystem.out.println()System.out.print()Soru — CevapKısa Hatırlatma

Java uygulamasının temel başlangıç noktası main metodudur.

En basit Java programlarından biri şu şekildedir:

public class Main {
    public static void main(String[] args) {
        System.out.println("Merhaba Java");
    }
}

public class Main

Burada Main adında bir sınıf tanımlanır.

Şimdilik sınıfların detayına girmeye gerek yoktur. İlerleyen konularda class yapısını ayrıntılı olarak inceleyeceğiz.

main Metodu

public static void main(String[] args)

Java programının başlangıç noktasıdır.

Program çalıştırıldığında Java bu metodu arar ve içindeki kodları çalıştırmaya başlar.

public, static, void ve String[] args bölümlerinin her birini ilerleyen konularda ayrı ayrı inceleyeceğiz.

Şimdilik bilinmesi gereken temel nokta:

main metodu programın giriş noktasıdır.

Kodların Çalışma Sırası

main metodunun içindeki kodlar normal şartlarda yukarıdan aşağıya doğru çalışır.

Örneğin:

public static void main(String[] args) {
    System.out.println("Bir");
    System.out.println("İki");
}

Çıktı:

Bir

İki

System.out.println()

Konsola çıktı vermek için kullanılır.

System.out.println("Merhaba");

Çıktı:

Merhaba

println, yazdırma işleminden sonra imleci bir alt satıra geçirir.

Örneğin:

System.out.println("Java");
System.out.println("Spring");

Çıktı:

Java

Spring

System.out.print()

print de konsola çıktı verir ancak yazdırma işleminden sonra alt satıra geçmez.

System.out.print("Java ");
System.out.print("Spring");

Çıktı:

Java Spring

Dolayısıyla temel fark:

println() → yazdırır ve alt satıra geçer.

print() → yazdırır ancak aynı satırda kalır.

Soru — Cevap

Soru: Java programı çalıştırıldığında ilk olarak hangi metod aranır?

Cevap: main metodu.

Soru: System.out.println("Merhaba"); satırının görevi nedir?

Cevap: Konsola Merhaba yazdırır ve ardından alt satıra geçer.

Soru: print() ile println() arasındaki temel fark nedir?

Cevap: println() yazdırdıktan sonra alt satıra geçer, print() ise aynı satırda kalır.

Kısa Hatırlatma

public static void main(String[] args)

→ Programın başlangıç noktasıdır.

System.out.println("Java");

→ Yazdırır ve alt satıra geçer.

System.out.print("Java");

→ Yazdırır ancak aynı satırda kalır.
