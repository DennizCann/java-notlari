2.1 Program Yapısı ve Temel Syntax

Programın İskeleti

Bu bölümde klasik Java program yapısını, konsola yazı yazdırmayı ve yorum satırlarını öğreneceğiz. İlk örneği Main.java dosyasına yazabilirsin:

public class Main {
    public static void main(String[] args) {
        System.out.println("Merhaba Java!");
    }
}

class Main, Main adlı sınıfı tanımlar. public class Main kullanıldığında dosyanın adı da Main.java olmalıdır. Büyük ve küçük harfler önemlidir.

main Metodu

Bu notlarda kullandığımız programların giriş noktası public static void main(String[] args) metodudur. Çalıştırma başladığında bu metodun içindeki komutlar yürütülür.

public erişimi, static nesne oluşturmadan çağrılabilmesini, void bir sonuç değeri döndürmemesini belirtir. String[] args komut satırından gelen metinleri alır. Şimdilik bu kalıbı tanıman yeterli; ayrıntılarını ileride işleyeceğiz.

Aşağıdaki kısa örneklerde sınıf ve main kalıbını tekrar yazmıyoruz. Örnekleri denerken kodları main metodunun süslü parantezleri arasına yerleştir.

Temel Syntax: İşaretler Ne Anlama Geliyor?

Syntax, dilin yazım kurallarıdır. { } bir kod bloğunun sınırlarını, ( ) metodun parametre veya gönderilen değer bölümünü belirtir. Yazdırma komutları ; ile biter. Sınıf ve main başlığındaki açılış süslü parantezinden sonra noktalı virgül koymayız.

"Merhaba" bir metindir; çift tırnaklar metnin sınırlarını gösterir, çıktıya yazılmaz. Java’da tek tırnak bir karakter içindir: 'A'. Çok karakterli bir metni tek tırnakla yazamayız.

Girintiler blokları okumayı kolaylaştırır. Bir satıra tek komut yazmak iyi bir alışkanlıktır; ancak editörde alt satıra geçmek, konsol çıktısında alt satıra geçmek anlamına gelmez.

Kodların Çalışma Sırası

Bu basit örneklerde komutlar yukarıdan aşağıya çalışır. İki komutun yerini değiştirirsen çıktı sırası da değişir.

System.out.println("Bir");
System.out.println("İki");

Çıktı:

Bir
İki

Sık Yapılan Yazım Hataları

system.out.println yerine System.out.println yazılır. Println yerine println kullanılır. Java büyük/küçük harfe duyarlıdır.

Eksik ;, kapanmayan çift tırnak ve eşleşmeyen { } işaretleri derleme hatasına yol açabilir. Editörün hata gösterdiği satırın hemen üstünü de kontrol et.

System.out.println("Merhaba", "Java"); iki ayrı metni bu şekilde kabul etmez. System.out.println("Merhaba " + "Java"); yazabilir veya iki ayrı yazdırma komutu kullanabilirsin.

2.2 print ve println ile Çıktı Verme

System.out.println()

System.out standart çıktı akışıdır; bu örneklerde çıktıyı IDE’nin konsolunda veya terminalde görürüz. println, verilen değeri yazdırıp mevcut satırı bitiren metoddur. Noktalar bu parçalara erişmek için kullanılır.

System.out.println("Java");
System.out.println("öğreniyorum.");

Çıktı:

Java
öğreniyorum.

Boş println() yalnızca satırı bitirir. Önceki satır zaten bitmişse arada boş bir satır oluşturur:

System.out.println("Başlangıç");
System.out.println();
System.out.println("Bitiş");

Çıktı:

Başlangıç

Bitiş

System.out.print() ve println() Birlikte

print yazdırdıktan sonra otomatik satır sonu eklemez. Sonraki çıktı aynı satırdan devam eder. Boşluk da kendiliğinden eklenmez; metnin içine yazmalısın.

System.out.print("Merhaba ");
System.out.print("Java");
System.out.println("!");
System.out.println("Yeni satır.");

Çıktı:

Merhaba Java!
Yeni satır.

Burada ilk iki komut aynı satırda kalır. Üçüncü komut önce ünlemi ekler, sonra satırı bitirir. Yani println yazmadan önce alt satıra geçmez.

print("") boş metin yazdırır ve satırı değiştirmez. println("") satırı bitirir. Parametresiz print() ise geçerli değildir.

Metin, Sayılar ve + İşareti

Sayılar tırnaksız yazılabilir. Tırnak içindeki işlem yalnızca metindir; tırnak dışındaki sayısal işlem hesaplanır:

System.out.println(25);
System.out.println(2 + 3);
System.out.println("2 + 3");

Çıktı:

25
5
2 + 3

+, sayılarda toplama; metinle birlikte kullanıldığında birleştirme yapabilir. İşlemin sırası önemlidir:

System.out.println("Sonuç: " + 2 + 3);
System.out.println("Sonuç: " + (2 + 3));
System.out.println(2 + 3 + " puan");

Çıktı:

Sonuç: 23
Sonuç: 5
5 puan

İlk satırda soldan başlayarak metin birleştirilir. İkinci satırda parantez, toplamanın önce yapılmasını sağlar. Üçüncü satırda iki sayı önce toplanır. Değişkenleri bir sonraki bölümde ekleyeceğiz.

Metin İçinde Özel Karakterler

Metnin içine tırnak veya satır sonu yazmak için kaçış dizileri kullanılır: \n yeni satır, \t sekme, \" çift tırnak, \\ ters eğik çizgi demektir.

System.out.println("Birinci satır\nİkinci satır");
System.out.println("Ali: \"Merhaba!\"");
System.out.println("C:\\Java\\Notlar");

Çıktı:

Birinci satır
İkinci satır
Ali: "Merhaba!"
C:\Java\Notlar

System.out.print("Ad\tPuan"); iki kelime arasına sekme koyar. Görünen aralık konsola göre değişebilir. print otomatik satır sonu eklemez ama metninde \n varsa o noktada alt satıra geçilir.

2.3 Comments: Yorum Satırları

Yorumlar kodu okuyan kişiye açıklama bırakır; Java bunları komut olarak çalıştırmaz. Özellikle bir işlemin neden yapıldığını açıklamak için kullanılır.

Tek satırlık yorum: // işaretinden satır sonuna kadar sürer. Ayrı bir satırda veya komutun sonunda bulunabilir.

// Kullanıcıyı karşıla
System.out.println("Hoş geldin!"); // Konsola yazdır

Çıktı:

Hoş geldin!

Blok yorum: /* ile başlar, */ ile biter. Birden fazla satıra yayılabilir. Blok yorumlar iç içe açılamaz.

/* Bu örnekte yalnızca
   başlangıç mesajı gösterilir. */
System.out.println("Başla");

Çıktı:

Başla

Javadoc yorumu: /** ... */ biçimindedir. Sınıf ve metod gibi yapıların önünde dokümantasyon açıklaması için kullanılır. Şimdilik biçimini tanıman yeterlidir.

/** Konsola selamlama yazdıran örnek uygulama. */
public class Main {
    public static void main(String[] args) {
        System.out.println("Merhaba!");
    }
}

Bir kod satırını geçici olarak devre dışı bırakmak için de yorum kullanabilirsin. Ancak tırnak içindeki yorum işaretleri sıradan metindir:

// System.out.println("Gizli mesaj");
System.out.println("// Bu metin ekrana yazılır");

Çıktı:

// Bu metin ekrana yazılır

Soru — Cevap

Soru: Aşağıdaki kodun çıktısı nedir? Önce kendin tahmin et.

System.out.print("A");
System.out.println("B");
// System.out.println("C");
System.out.print("D");

Çıktı:

AB
D

Cevap: A ile B aynı satırdadır; B’den sonra satır biter. C yorum içinde olduğu için yazılmaz. D’den sonra otomatik satır sonu eklenmez.

Soru: println("Toplam: " + 4 + 6) ile println("Toplam: " + (4 + 6)) neden farklıdır? Cevap: İlki Toplam: 46, ikincisi Toplam: 10 yazar; parantez toplama işlemini öne alır.

Soru: Her // yorum başlatır mı? Cevap: Hayır. Metnin çift tırnakları içindeyse çıktının bir parçasıdır.

Kısa Hatırlatma

main → başlangıç noktası · print → otomatik satır sonu yok · println → yazdır ve satırı bitir · ; → komut sonu · // ve /* */ → yorum.
