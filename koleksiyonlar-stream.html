5.1 Array Nedir?

Array, aynı veri tipinden birden fazla değeri tek yapı içinde tutmamızı sağlar.

int[] numbers = {10, 20, 30, 40};

Elemanlara index ile erişilir.

System.out.println(numbers[0]); // 10

System.out.println(numbers[2]); // 30

Java’da indexler 0’dan başlar.

5.2 Array Oluşturma ve Eleman Atama

Array baştan değerlerle oluşturulabilir:

int[] numbers = {10, 20, 30};

Veya önce boyutu belirlenebilir:

int[] numbers = new int[3];
numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;

new int[3], 3 elemanlık bir array oluşturur.

Geçerli indexler:

0, 1, 2

5.3 Array length

Array’in eleman sayısını öğrenmek için length kullanılır.

int[] numbers = {10, 20, 30, 40};

System.out.println(numbers.length); // 4

5.4 Array’i Döngü ile Gezmek

Array elemanları klasik for döngüsüyle gezilebilir.

int[] numbers = {10, 20, 30};
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

Burada i, array indexini temsil eder.

5.5 Array’i for-each ile Gezmek

Index bilgisine ihtiyaç yoksa enhanced for kullanılabilir.

String[] names = {"Ali", "Ayşe", "Deniz"};
for (String name : names) {
    System.out.println(name);
}

Her eleman sırayla name değişkenine alınır.

5.6 Çok Boyutlu Array

Bir array’in elemanları da array olabilir.

int[][] matrix = {
    {1, 2},
    {3, 4}
};

Örnek:

matrix[0][0] // 1

matrix[1][0] // 3

İlk index satırı, ikinci index ise o satırdaki elemanı belirtir.

Koleksiyonlar

5.7 ArrayList

ArrayList, boyutu dinamik olarak değişebilen bir listedir.

ArrayList<String> names = new ArrayList<>();
names.add("Ali");
names.add("Ayşe");
names.add("Deniz");

Eleman okuma:

names.get(1); // Ayşe

Eleman sayısı:

names.size(); // 3

Temel fark:

Array → sabit boyut

ArrayList → dinamik boyut

5.8 ArrayList Temel Metodları

names.add("Ali"); // eleman ekleme

names.get(0); // eleman okuma

names.set(0, "Deniz"); // eleman değiştirme

names.remove(0); // eleman silme

names.contains("Ali"); // içeriyor mu?

names.size(); // eleman sayısı

5.9 List Interface

ArrayList, List interface’ini implement eden sınıflardan biridir.

Genellikle:

List<String> names = new ArrayList<>();

kullanımı tercih edilir.

Temel fikir:

List → sözleşme

ArrayList → implementasyon

Bu yaklaşım kodu daha esnek hale getirir.

5.10 Set ve HashSet

Set, tekrar eden elemanları tutmaz.

Set<String> names = new HashSet<>();
names.add("Ali");
names.add("Ayşe");
names.add("Ali");

System.out.println(names.size()); // 2

Temel fark:

List → tekrar eden elemanlara izin verir

Set → unique elemanlar tutar

5.11 Map ve HashMap

Map, verileri key-value şeklinde tutar.

Map<Integer, String> users = new HashMap<>();
users.put(1, "Ali");
users.put(2, "Ayşe");
users.put(3, "Deniz");

Bir değeri key ile alabiliriz:

users.get(2); // Ayşe

5.12 Map Temel Metodları

map.put(key, value); // ekleme veya güncelleme

map.get(key); // değer alma

map.remove(key); // silme

map.containsKey(key); // key var mı?

map.containsValue(value); // value var mı?

map.size(); // eleman sayısı

Aynı key tekrar kullanılırsa eski value güncellenir.

map.put(1, "Ali");
map.put(1, "Deniz");

Son durumda:

1 → Deniz

5.13 Iterator

Iterator, collection elemanlarını sırayla dolaşmak için kullanılır.

List<String> names = new ArrayList<>();
names.add("Ali");
names.add("Ayşe");
names.add("Deniz");
Iterator<String> iterator = names.iterator();
while (iterator.hasNext()) {
    String name = iterator.next();
    System.out.println(name);
}

Temel metodlar:

hasNext() → sırada eleman var mı?

next() → sıradaki elemanı getir

5.14 Koleksiyonlarda Klasik Filtreleme

Bir koşula uyan elemanları döngü ve if ile seçebiliriz.

List<Integer> ages = List.of(15, 20, 17, 30);
for (Integer age : ages) {
    if (age >= 18) {
        System.out.println(age);
    }
}

Çıktı:

20

30

Lambda ve Stream API

5.15 Lambda Expressions

Lambda, kısa biçimde bir davranış tanımlamamızı sağlar.

Örnek:

x -> x * 2

Burada:

x → parametre

-> → lambda operatörü

x * 2 → yapılacak işlem

Birden fazla parametre olabilir:

(a, b) -> a + b

Boolean sonuç döndüren bir lambda:

x -> x % 2 == 0

Bu ifade sayının çift olup olmadığını kontrol eder.

Birden fazla işlem yapılacaksa blok kullanılabilir:

name -> {
    System.out.println(name);
    System.out.println(name.length());
}

5.16 forEach() ve removeIf()

forEach()

Collection içindeki her eleman için bir işlem yapar.

List<String> names = List.of("Ali", "Ayşe", "Deniz");
names.forEach(name -> System.out.println(name));

removeIf()

Belirtilen koşulu sağlayan elemanları siler.

List<Integer> numbers =

        new ArrayList<>(List.of(1, 2, 3, 4, 5, 6));
numbers.removeIf(number -> number % 2 == 0);

Sonuç:

[1, 3, 5]

5.17 Stream API’ye Giriş

Stream API, collection verileri üzerinde filtreleme, dönüştürme ve sıralama gibi işlemler yapmamızı sağlar.

List<Integer> numbers = List.of(1, 2, 3, 4, 5, 6);

List<Integer> result = numbers.stream()

        .filter(number -> number % 2 == 0)
        .toList();

Sonuç:

[2, 4, 6]

Akış:

Collection
↓
stream()
↓
işlemler
↓
sonuç

Stream, collection’ın kendisi değildir. Collection verileri üzerinde işlem yapmak için oluşturulan bir akıştır.

5.18 filter()

filter(), belirli koşulu sağlayan elemanları seçer.

List<Integer> numbers = List.of(5, 12, 8, 20);

List<Integer> result = numbers.stream()

        .filter(number -> number > 10)
        .toList();

Sonuç:

[12, 20]

Kısa mantık:

filter() → eleman seçer.

5.19 map()

map(), her elemanı başka bir değere dönüştürür.

List<Integer> numbers = List.of(1, 2, 3);

List<Integer> result = numbers.stream()

        .map(number -> number * 10)
        .toList();

Sonuç:

[10, 20, 30]

String örneği:

List<String> names = List.of("ali", "ayşe", "deniz");

List<String> result = names.stream()

        .map(name -> name.toUpperCase())
        .toList();

Sonuç:

[ALI, AYŞE, DENİZ]

Kısa fark:

filter() → seçer

map() → dönüştürür

5.20 sorted()

sorted(), stream içindeki elemanları doğal sıralamaya göre sıralar.

List<Integer> numbers = List.of(9, 3, 6, 1);

List<Integer> result = numbers.stream()

        .sorted()
        .toList();

Sonuç:

[1, 3, 6, 9]

Sayılarda küçükten büyüğe, String değerlerde ise doğal alfabetik sıralama uygulanır.
